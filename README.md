# Afterglow — Social Safety Bracelet Demo

A polished, interactive concept prototype for a community-led nightlife safety experience combining an Italian charm bracelet with a trusted-circle mobile app.

## Live experience

Open `index.html` locally, or publish the repository with GitHub Pages.

## What the demo shows

- A professional landing page explaining the protected market
- A wearable concept inspired by Italian charm bracelets
- Trusted-circle and night-out session interfaces
- An interactive potential-risk simulation
- A private haptic check-in flow
- Trusted-friend notification and location-sharing concepts
- Explicit privacy, consent, and product-claim boundaries
- Responsive layouts for desktop and mobile

## Primary market

The initial protected users are college-age young adults, approximately 18–24, navigating house parties, campus events, concerts, festivals, and nightlife. The adoption path starts with trusted friend groups and student communities, followed by campus programs, event organizers, and venues.

## Important prototype limitation

This concept demonstrates possible motion, inactivity, separation, missed-check-in, and manual distress signals. It does **not** claim to reliably detect intoxication, drink spiking, assault, consent, or a specific medical emergency. It is not a replacement for emergency services.

## Run locally

No installation or build tooling is required.

```bash
git clone https://github.com/shayan-tilly/social-safety-bracelet-demo.git
cd social-safety-bracelet-demo
open index.html
```

You can also double-click `index.html` in Finder or serve the folder with any static web server.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for the public link to appear.

The expected URL is:

`https://shayan-tilly.github.io/social-safety-bracelet-demo/`

## Add it to your GitHub profile

After publishing, open your GitHub profile, choose **Customize your pins**, and pin `social-safety-bracelet-demo`. Add the GitHub Pages link to the repository's **About** section as the website URL.
